## Compared with Auto Arkham (request #10616, founder #1323; shipped as 0.9.2)

Our four layers: (a) `AGENTS.md`, loaded by Claude Code as project instructions; (b) `--agent .claude/agents/<lane>.md`, generated by `tools/tower/agentgen.py`; (c) the appended harness (`tools/tower/cc/settings.py` `harness_text`, "Lane harness (Claude Code)"); (d) `.opencode/skills` linked as a skills root (`lane-protocol`, `review-board`, `direction-duties`, `common-process`). The starter's layers: `CLAUDE.md`/`AGENTS.md` marked block, `.tower/lanes/<lane>.md`, `.tower/PROTOCOL.md`, `.claude/skills/`. Same = same rule and place in kind; Different = the rule is there but worded or placed differently; Ported = added to PROTOCOL.md in 0.9.2; Skip = project-specific or already covered.

### Ported in 0.9.2 (PROTOCOL.md only)

Hard rules: denied call, hook refusal, subagent briefing. Lane close-out: worktrees, retry once, no force/rebase/amend. New "Shared checkout". New "When to post an item". Game content: none. Tests: full suite `OK`; `shipped.json` carries the new text so `dah update` swaps untouched copies.

### Not ported

- `dah find` (search tasks, items, memos): needs a CLI command and a store query; left for a later release.
- Per-project checklists (quality-review, founder-basics): project content.
- Claude Code's own system text (background agents, no fabricated results).
